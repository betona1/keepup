# 로그챌린지 업데이트 기록

출시할 때마다 `store/update/<버전>/` 폴더를 만들고 아래 파일을 둔다.

| 파일 | 용도 |
|---|---|
| `LogChallenge-<버전>-release.aab` | Play Console 업로드용 (정식 업로드 키 서명) — 용량 때문에 git 제외 |
| `LogChallenge-<버전>-release.apk` | 폰에 직접 설치용 (`adb install -r`, 데이터 보존) — git 제외 |
| `출시노트_ko-KR.txt` | Play Console '출시 노트'에 그대로 붙여넣기 (`<ko-KR> … </ko-KR>`, 500자 이내) |

그리고 이 파일 맨 위에 버전 기록을 추가한다.

## 1.6.1 (build 18) — 2026-10-06
- 폴더: `store/update/1.6.1/`
- **상태: 빌드 완료(신고 기능 포함) · 제출 대기** — 1.6.0 심사가 끝난 뒤 제출 (심사 중에 새 버전을 올리면 1.6.0 검토가 대체됨).
  1.6.0이 'UGC 신고 기능' 사유로 거부되면 이 1.6.1로 바로 재제출
- **수업 시간표 마감** (과제 점검형 · 매주): 요일별 수업 시작 시각 + 마감 규칙 '수업 N분 전' / '수업 전날 밤(23:59 등)'
  - 이번 회차 마감이 지나면 제출 화면이 자동으로 다음 회차를 연다 (서버 `currentSlot`)
  - 마감 알람도 수업 기준 마감에 맞춰 울림 (`Routine.dueDeadlines`, 음수 분 = 전날)
- **반장 넘기기** 메뉴(동호회 ⋮) — 넘기면 본인은 자동 부반장
- **신고 기능** (Play UGC 정책 대비): 동호회 게시글(⋮ 신고)·댓글(🚩/길게 누르기)·과제 제출물(상단 🚩) 신고 —
  사유 6종(욕설·음란·괴롭힘·스팸·개인정보·기타)+메모, 같은 대상 1인 1회, 내 글은 신고 불가.
  메인 관리자 화면 **'신고' 탭**에서 미리보기(글·사진·첨부) 보고 **내용 삭제 / 동호회 숨기기 / 문제없음** 처리.
  관리자는 '신고가 접수된 동호회'의 첨부만 열람 가능. DB 마이그레이션 0005(`crew_reports`) 적용·배포 완료
- 메인 관리자: 동호회 목록·Pro 상태에 메인 관리자 여부 포함, 현황에서 해체 동호회 과제 제외
- 서버: DB 마이그레이션 0004(`crew_tasks.due_times` = 수업 시간표 JSON)·0005(`crew_reports`) 적용·배포 완료
- Play Console: 데이터 보안·콘텐츠 등급 변경 없음 (1.6.0에서 처리) → AAB + 출시노트만
